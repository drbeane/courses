## Format Is Part of the Description

Week 2: describe the **task**.
This week: describe the **shape of the output**.

- "Make it look nice" gets you something polished but hard to reuse, check, or move to another tool.
- Naming a format, such as "a CSV with these four columns," gets you something you can edit, check, and move.
- The format you ask for also decides what you can do next: sort it, chart it, feed it to a program.

---

## Structured Files

Formats people **and** AI both read and write well:

| Format | Good for |
|---|---|
| **Markdown** | Documents, notes, instructions |
| **CSV** | Tables of data |
| **JSON** | Structured records, app data |
| **Mermaid** | Diagrams as text |

All four are plain text: nothing is hidden.

---

## Why They Matter

- They're easy to check, edit, and keep versions of, because you can read every character.
- They move cleanly between tools: chat, spreadsheets, code, and agents all read them.
- Instruction files and skills (week 7) **are** Markdown files.
- Programs exchange data with models as JSON (week 11).

Learning to read them now pays off for the rest of the term.

## Markdown in 30 Seconds

```markdown
# Heading
## Subheading
- bullet
**bold**, *italic*
| table | row |
```

Chat replies are written in Markdown. So are these slides. When you copy a reply, you're copying Markdown.

## CSV

```
student_id,major,credits,gpa
1041,Nursing,62,3.4
1042,"Business, Marketing",45,3.1
1043,Cybersecurity,,3.8
```

- One row per line, commas between values
- Quotes around a value that contains a comma
- Everything is text: nothing says `gpa` is a number

---

## What Goes Wrong in a CSV

- An unquoted comma inside a value shifts the rest of the row one column over.
- The same thing spelled different ways: "NY", "New York", "new york."
- Mixed date formats, such as 3/4/2026 and 2026-04-03, in one column.
- `$1,200` and `45%` stored as text, so they can't be added or averaged.
- Blank cells: does blank mean zero, unknown, or not applicable?

## JSON

```json
{
  "name": "Ada Okafor",
  "year": 2027,
  "majors": ["Data Science", "Mathematics"],
  "advisor": { "name": "Dr. Lee" }
}
```

- Objects in `{ }`, lists in `[ ]`
- Can nest, which a CSV can't
- Strict: one missing comma breaks the file

---

## Mermaid in 30 Seconds

```text
flowchart LR
  A[Question] --> B[Search] --> C[Read] --> D[Report]
```

Ask: *"Draw this process as a Mermaid flowchart."*

- Many chat tools and editors draw the diagram from this text.
- To change a step, edit one line. No redrawing, no image editor.

You can fix a text diagram. You can't fix an image.

---

## Choosing a Format

| You want | Ask for |
|---|---|
| A document or instructions | Markdown |
| A table to sort or chart | CSV |
| Nested records, output for a program | JSON |
| A diagram | Mermaid |

Work in a plain format while checking. Convert to a finished file at the end.
