# Three-Vendor Comparison
### Week 1 · Lab and Assignment
COSC-300/500 Applied AI Essentials

---

## Before the Lab

- Complete Claude Academy: **AI Fluency: Framework and foundations**, lessons 1–5.
- Set up your tools: **Claude Pro**, Maryville **Copilot Chat**, and free **NotebookLM**.
- Install the **Claude desktop app**. You'll need it from week 6 on.
- Pick a task from your own coursework or job to bring to the lab.

---

## The Lab

1. Pick a realistic task from your coursework or job, one where you can judge the result.
2. Run the same prompt on **three chat tools**:
   - Claude
   - Copilot Chat
   - one free tool (ChatGPT Free, Gemini, …)
3. Run it on **two Claude models or effort levels**.
4. Save every prompt and output. You'll need them for the assignment.

---

## What to Compare

- **Accuracy**: is it right? Check any facts you can.
- **Usefulness**: would you actually use it, or would you have to redo it?
- **Speed**: how long did each one take?
- **Format and tone**: does it fit where the result is going?
- **Capabilities**: what each tool could and couldn't do, such as search, files, or length

Start your comparison table now, while the outputs are in front of you.

---

## Share-Out

- Which output would you actually use, and what would you still change in it?
- Where did the tools differ most: facts, structure, tone, or what they could do?
- Did the bigger model or more effort help, or did it just take longer and cost more?
- Did anything surprise you about a tool you already use?

---

## Assignment: Three-Vendor Comparison

- One task, three chat tools, two Claude settings
- One-page comparison table
- 400-word evaluation: which output you'd use and why
- Include all prompts
- **500 extension:** relate findings to a published model card or system card
- About 3 hours
