## The Centerpiece of the Course

Until now: you **talk**, the AI **answers**, you **copy** the result out.

From now on: you **delegate**, the agent **works on your files**, you **review**.

- The agent can take dozens of steps without you, so it can finish work that would take you an hour.
- It also acts on real files, so its mistakes change things instead of just sitting in a chat.
- Everything from weeks 1–5 still applies. Now it applies with higher stakes.

---

## Chat vs Agent

| Chat | Agent |
|---|---|
| Answers one message | Works through many steps |
| Sees what you paste or upload | Reads your folder directly |
| Returns text | Saves finished files in place |
| You run every step | It plans, acts, checks its own work |

---

## What Makes an Agent

- **Model**: does the thinking, decides what to do next
- **Tools**: the actions available to it, such as reading files, writing files, running code, and searching
- **Harness**: the program that runs the loop, carries out tool calls, and enforces permissions

The same model is far more powerful, and far riskier, with tools and a harness around it.

---

## The Tool-Use Loop

1. The model decides it needs a tool, and says which one and with what input.
2. The harness runs the tool, if permissions allow it.
3. The result goes back into the model's context.
4. Repeat until the model decides the task is done.

This loop is what lets it **check its own work**: it can reopen a file it just wrote and look for problems.

---

## What the Loop Looks Like

| Step | The model decides | Tool call |
|---|---|---|
| 1 | "See what's here" | List the folder |
| 2 | "Start with the schedule" | Read `schedule.docx` |
| 3 | "Check the invitation" | Read `invitation.pdf` |
| 4 | "Write the report" | Write `conflicts.md` |
| 5 | "Is it complete?" | Read `conflicts.md` |

Slower than chat, and it uses more of your allowance.


---

## Agents Make Mistakes Differently

- An early mistake **carries forward**. If it misreads the first file, every later step builds on the misreading.
- Mistakes now have **effects**: files get renamed, overwritten, or deleted.
- You see the result only at the end, after many decisions you didn't watch.

That's why the next two topics cover briefs, plans, approvals, and review.

---

## Local Agent: Claude Cowork

- It runs from the **Claude desktop app** on your computer.
- It works on a **folder you choose**, and only that folder.
- It can read, write, and organize files, and produce finished deliverables like reports and spreadsheets.
- It asks before risky actions, such as deleting files.

## Demo: A Messy Folder Becomes a Report

1. Start with a folder of inconsistent documents.
2. Write the brief: reconcile them and report conflicts.
3. **Review the plan first**, before anything changes.
4. Watch it work, step by step.
5. Check the result against the brief.

Watch for the moment it decides something you'd have decided differently.
