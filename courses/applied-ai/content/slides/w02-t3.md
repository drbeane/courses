## Markdown in One Slide

| You type | You get |
|---|---|
| `# Title` | A heading |
| `- item` | A bullet |
| `1. step` | A numbered item |
| `**bold**`, `*italic*` | Bold, italic |
| `[words](address)` | A link |

Markdown is plain text, so it opens anywhere and hides nothing. AI tools read it well and write it by default.

---

## Ask for Output as Markdown

> Put the summary in a Markdown file I can download. Use a heading for each question and a Sources section at the end.

- It keeps the headings, lists, and tables from the chat.
- It converts easily to Word, PDF, or a web page.
- It's easy to check, because there's no hidden formatting.


---

## Why Long Chats Get Expensive

- Every message makes the model reread the whole chat from the start.
- Message 40 carries the 39 before it, plus every file attached along the way.
- Long chats also get **worse**: details get crowded out, old mistakes repeat, and the topic drifts.

When a chat has done its job, **start a new one**, and bring along only what you need.

---

## The Handoff File

Ask the AI to summarize the chat in these sections:

**Goal · What We Decided · Current Draft · Open Questions · Next Steps**

1. Read it and correct it. The summary can drop or distort decisions.
2. Save it as a `.md` file.
3. Start a new chat with it: "Here's where we left off."

---

## Why a File?

- **It lasts**: it's still there next week, after the chat has scrolled away.
- **It travels**: you can hand it to other tools, projects, agents, or group partners.
- **It grows**: update it after each work session, so it always reflects the current state.

Agents in Weeks 6 and 7 keep track of their work the same way: in plain files they read and update.
