## An Exploratory Week

- You'll **build** a small AI program that talks to a model directly.
- Claude Code writes the code. You specify what it should do, run it, and inspect what goes back and forth.
- The goal is **understanding** how AI products are put together, not engineering fluency.
- By the end of the week, the chat apps, copilots, and agents from earlier weeks should look a lot less mysterious.

---

## What the Apps Do Behind the Scenes

Every chat app, copilot, and agent:

1. Builds a **request**: instructions, messages, files, tools
2. Sends it to a model through an **API**
3. Gets a **response**
4. Does something with it

Companies build products on that loop.

---

## Chat App vs API

| | Chat app | API |
|---|---|---|
| Used by | A person | A program |
| System prompt | The vendor's, hidden | **Yours** |
| Memory, projects | Built in | Only if you build them |
| Payment | Subscription | Per token |

Same model. The app is a product built on the API.

---

## Anatomy of an API Call

```json
{
  "model": "claude-sonnet-...",
  "system": "You are a concise tutor.",
  "messages": [
    {"role": "user", "content": "Explain recursion."}
  ],
  "max_tokens": 500,
  "temperature": 0.7
}
```


---

## The Pieces

| Part | What it does |
|---|---|
| **model** | Which model answers |
| **system** | Standing instructions |
| **messages** | The conversation so far |
| **max_tokens** | Cap on response length |
| **temperature** | How much randomness (week 1's sampling) |

---

## What Comes Back

```json
{
  "content": [{"type": "text", "text": "Recursion is..."}],
  "stop_reason": "end_turn",
  "usage": {"input_tokens": 31, "output_tokens": 74}
}
```

- **content**: the reply
- **stop_reason**: finished, hit the limit, or wants a tool
- **usage**: what you're billed for

---

## The Model Remembers Nothing

- Each API call is **independent**. The model keeps nothing from one call to the next.
- A "conversation" is your program resending the whole history every time.
- That's why long chats cost more and degrade, as you saw in week 2.
- It also means your program decides what the model remembers: it can trim, summarize, or add to the history.
