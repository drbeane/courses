## Markdown in One Slide

| You type | You get |
|---|---|
| `# Title` | A heading |
| `- item` | A bullet |
| `1. step` | A numbered item |
| `**bold**`, `*italic*` | Bold, italic |
| `[words](address)` | A link |

Plain text: opens anywhere, nothing hidden.

---

## Ask for Output as Markdown

> Put the summary in a Markdown file I can download. Use a heading for each question and a Sources section at the end.

- Keeps headings, lists, and tables
- Converts to Word, PDF, or a web page
- Easy to check

## Why Long Chats Get Expensive

- Every message rereads the whole chat
- Message 40 carries the 39 before it, plus every file
- Long chats also get **worse**: crowded-out details, old mistakes, drift

When a chat has done its job, **start a new one**.

---

## The Handoff File

Ask for sections:

**Goal · What We Decided · Current Draft · Open Questions · Next Steps**

1. Read it and correct it
2. Save it as a `.md` file
3. Start a new chat with it: "Here's where we left off."

---

## Why a File?

- **It lasts**: it's there next week
- **It travels**: other tools, projects, agents, group partners
- **It grows**: update it after each session

Agents in Weeks 6 and 7 keep track of work the same way.
