# Lesson Template

Every lesson file follows this structure, so lessons can later be converted to Canvas pages or a book format with minimal rework.

```markdown
# MM-LL — Lesson Title

**Module:** N — Module Title
**Estimated time:** XX minutes (reading + activity)
**Content note:** (only if the lesson discusses sexual abuse, suicide, violence, etc.)

## Learning objectives
By the end of this lesson, you will be able to:
1. …
2. …
3. …

## Opening case
A short, dated, real case (or clearly labeled hypothetical) that motivates the lesson.

## The case for the system
What the system is for, who gains, and the evidence that it helps. State it in its strongest form before turning to what goes wrong.

## Core ideas
2–5 subsections of instructional content. Plain language; technical depth where it changes the ethical analysis.

## Applying the frameworks
Connects the case to Module 1 frameworks (consequences, duties/rights, decency lenses, justice, five principles).

## Discussion questions
3–5 questions. At least one asks students to argue the side they disagree with.

## Activity
A short, bounded task (10–30 minutes). Labs are longer.

## Key terms
Short glossary.

## Connections
Links to other lessons and to assessments.

## Sources and further reading
Dated sources. Legal or policy facts carry an "as of" date. Items marked ⚠ need re-verification before each offering.
```

## Style rules

- Present contested questions as contested. Give the strongest version of each side.
- Label claims as measured, estimated, forecast or speculative when it matters.
- Date every legal status claim.
- Link each further-reading resource to its official publication, author manuscript, or institutional repository. Label access as free full text, free manuscript, paid/library, partial/preview, or unverified; an abstract or free sample is not the assigned full reading. Record versions and unresolved access in the [Reading Access Register](_Research/04%20-%20Reading%20Access%20Register.md).
- Use real cases where possible; label hypotheticals.
- Avoid graphic detail in sensitive cases. Describe harms at the level needed for analysis.
- Each lesson should be readable in 20–30 minutes; activities add 10–30 minutes.
