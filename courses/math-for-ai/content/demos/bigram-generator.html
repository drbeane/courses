What to notice

  1. The model is nothing more than a table of proportions. "Training" it means counting pairs of neighboring tokens and dividing each count by its row total.
  2. Every pair of neighboring words in the output appeared somewhere in the training text, so short stretches look sensible. Longer stretches drift, because the model remembers only one token.
  3. Where a token is always followed by the same token, the probability is 1 and the model has no choice. Where several tokens can follow, the output branches.
  4. Lower the temperature and the model keeps choosing the most common continuation, so it repeats itself. Raise it and rare continuations appear more often.
  5. Perplexity is the number of equally likely options the model was, on average, choosing among. Text built from forced choices has a perplexity near 1.
  6. A large language model runs this same loop: get a probability for every token, sample one, add it, repeat. It differs in how the probabilities are calculated, and in using thousands of earlier tokens to do it.
