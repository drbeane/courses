What to notice

  1. total is set to 0 once, before the loop. If that line were inside the loop, the total would reset on every pass.
  2. range(1, N + 1) stops one short of its second value. To include N, the code has to ask for N + 1.
  3. The loop body runs N times. Each pass does two things: it works out one term, then adds it to the total.
  4. The lower and upper limits on the sigma match the two values in range. The expression to the right of the sigma matches the line that sets new_term.
  5. For consecutive integers and for squares there is a shortcut formula. Compare it with the loop's answer once the loop ends.
