## Simulating samples for approximation

We do not always have access to the PMF for a random variable in which we are interested. This might occur because the values of the random variable are generated by a complicated process that is difficult to model perfectly, or perhaps because the random variable in question is defined as a complicated function of one or more other random variables. In some cases, it might be possible for us to construct a PMF for the random variable of interest, but it might be difficult to do so.

An alternate approach that can sometimes be used is to simulate a sample of observations of the random variable and then use the observations in the sample to approximate the quantity or quantities that we are interested in. If the sample is large enough, these approximations could be very close to the true value. This approach, known as **Monte Carlo Sampling**, can be quite effective if we are able to quickly generate large samples for the variable in question.

To demonstrate this concept, we will return to the "game of chance" example that we have been considering throughout the lessons this week. Recall that in that example, we let $X$ be a random variable representing the amount paid by the game during a single attempt. The PMF for $X$ is provided in the table below.

| $x$ | 0 | 1 | 5 | 10 | 50 | 100 |
|---|---|---|---|---|---|---|
| $p(x)$ | 0.40 | 0.25 | 0.20 | 0.10 | 0.04 | 0.01 |

We mentioned that sampling techniques are typically used when we do not have access to the PMF for the random variable. We do know the PMF for the game of chance example, but we can still use it to demonstrate the concepts in this lesson. And since we do know the PMF, we can compare the results of our simulations with the true values calculated using the PMF.

We will start by generating a sample of observations for $X$. Since we know the PMF, we can generate our sample using the function `np.random.choice()`. We will need to provide this function with an array representing the values of the random variable and an array containing the corresponding probabilities. This is demonstrated in the code block below. Note that we are drawing a sample of 10,000 observations. You are encouraged to experiment with this sample size in the demonstration notebook.

```
np.random.seed(25)                                    # Set seed for reproducibility
x = np.array([0, 1, 5, 10, 50, 100])                  # Define value array
p = np.array([0.40, 0.25, 0.20, 0.10, 0.04, 0.01])    # Define probability array
sample = np.random.choice(x, size=10000, p=p)         # Generate Sample
```

## Estimating the distribution

We can use a sufficiently large sample drawn from a random variable $X$ to estimate the probability mass function for that random variable. This is accomplished by calculating the proportion of observations in the sample with each possible value of $X$ and then using these proportions as approximations for the corresponding probabilities.

In the code cell below, we use the function `np.unique()` to calculate the proportions of each value appearing in the sample.

```
values, counts = np.unique(sample, return_counts=True)  # Determine values and counts
props = counts / counts.sum()                           # Calculate proportions
```

If setting a seed of 25 when generating the sample, then the value of `props` calculated in the code cell above will be as shown below.

`props = [0.3942 0.2506 0.2031 0.1012 0.041 0.0099]`

Note that these proportions are very close to the probabilities that define our distributions.

`p = [0.40 0.25 0.20 0.10 0.04 0.01]`

We can now estimate a probability or statistic related to $X$ by using the array `props` as a stand-in or proxy for the array `p` that represents the PMF. Although this is possible, we will see that there are other, often more convenient, ways of estimating these quantities that do not actually require us to explicitly calculate the proportions. We will now demonstrate this for the mean and standard deviation.

## Estimating statistics from a sample

As mentioned in the previous lesson, we can use a sample statistic as an approximation of the corresponding population statistic for the random variable from which the sample was drawn. In the code block below, we calculate the mean and standard deviation of the sample we have drawn.

```
sample_mean = np.mean(sample)           # Calculate mean of sample
sample_std = np.std(sample, ddof=1)     # Calculate std dev of sample
```

If a seed of 25 was set before drawing the sample, the sample mean should be about 5.32, and the sample standard deviation should be about 13.74. The true values for the population mean and population standard deviation (calculated [here](https://colab.research.google.com/drive/1Gkev4Oy9nW6-dc-Lo1IXYIs8ic4-UH7l#scrollTo=CvuSve0hc5dM)) were 5.25 and about 13.7. We see that the sample statistics provide reasonable approximations for the population statistics in this case. We can improve the quality of the approximation by increasing the size of the sample.

## Estimating probabilities from a sample

Next, we will consider how to use a sample to estimate the probability of an event $E$. To do so, we will create a Boolean array that assigns `True` to any observation in the sample that satisfies the event, and `False` to any observation that does not satisfy the event. We then pass the Boolean array to the function `np.mean()`. The resulting value can be used as an approximation for $P\left\lbrack E\right\rbrack$.

Let's explain why this works. The Boolean array indicates which observations satisfy the event $E$ and which do not. If we were to sum the values in this array, the `True` values would each be treated as 1, and the `False` values would each be treated as 0. The sum would then provide us with a count of the observations that satisfy $E$. If we were to divide this count by the total number of observations, that would provide us with a proportion of observations that satisfy the event, and that proportion can be used as an estimate for the probability $P\left\lbrack E\right\rbrack$. But if we sum an array and then divide by the length of that array, we are, in fact, calculating a mean of the values in the array. So, we can use `np.mean()` with a Boolean array to estimate probabilities.

We demonstrate this concept by using the sample to estimate the following probabilities: $P[X=5]$, $P[X < 5]$, and $P[X \geq 5]$.

```
P1 = np.mean(sample == 5)     # Approximate P[X = 5]  (result is approx 0.20)
P2 = np.mean(sample < 5)      # Approximate P[X < 5]  (result is approx 0.65)
P3 = np.mean(sample >= 5)     # Approximate P[X >= 5] (result is approx 0.35)
```

The code above generates the following probability approximations:

$P[X=5] \approx 0.2031$, $P[X < 5] \approx 0.6448$, $P[X \geq 5] \approx 0.3552$

Recall that the true values for these probabilities are as follows:

$P[X=5] = 0.20$, $P[X < 5] = 0.65$, $P[X \geq 5] = 0.35$

## Example: Rolling two dice

We will now demonstrate these ideas in an example in which we do not have immediate access to the PMF for the random variable of interest. For this example, consider the experiment of rolling two dice. Define a random variable $T$ to be the sum of the two dice. The support of $T$ would then be the collection of integers from 2 to 12 (inclusive). It is possible to use concepts from probability theory that have not been discussed in this course to determine the PMF of $T$. It is not a particularly difficult task when you have the correct tools, but we can also use Python to easily generate a very good approximation for the as-yet-unknown PMF.

We will start by simulating 100,000 rolls of the 2 dice by using `np.random.choice()` to generate a 2D array with shape `(100000,2)` and containing values selected at random from 1 - 6. We will then sum across the rows to generate 100,000 observations of $T$. We store these observations in an array named `totals`.

```
np.random.seed(17)              # Set seed
rolls = np.random.choice(       # Generate sample
    range(1,7),                 # Sampling from values 1 - 6
    size=(100_000, 2)           # Sampling 100,000 pairs of values
)
totals = rolls.sum(axis=1)      # Calculate sum of each pair
```

We will now estimate the PMF by calculating the proportions observed for each possible value of $T$.

```
values, counts = np.unique(totals, return_counts=True)
props = counts / counts.sum()
```

When using a seed of 17 (as above), each of the values stored in `props` will be within 0.0021 of the true value of the corresponding probability. The figure below shows the approximate PMF as represented by the `props` array.

We will now estimate $E\left[ T \right]$ and $SD\left[T\right]$ by calculating the mean and standard deviation of our simulated sample.

```
sample_mean = np.mean(totals)           # Calculate mean of sample
sample_std = np.std(totals, ddof=1)     # Calculate std dev of sample
```

We will conclude this lesson by estimating a few probabilities. In particular, we will estimate $P\left[ T ~\leq~ 7 \right]$ and $P\left[5 ~\leq~ T ~\leq~ 9 \right]$. Note that we will need to use the Boolean `&` operation and two array comparisons to estimate $P\left[5 ~\leq~ T ~\leq~ 9 \right]$.

```
P1 = np.mean(totals <= 7)            # Approximate P[T <= 7]
E = (totals >= 5) & (totals <= 9)    # Select observations that satisfy 5 <= T <= 9
P2 = np.mean(E)                      # Approximate P[5 <= T <= 9]
```

The code above produced the following two estimates: $P\left[ T ~\leq~ 7 \right] \approx 0.58207$ and $P\left[5 ~\leq~ T ~\leq~ 9 \right] \approx 0.66887$.

## Example: Expected reward of a strategy

Monte Carlo sampling is especially useful for comparing strategies in a game, because the expected result of a strategy can be estimated without working out any probabilities by hand.

Consider a simple game. You roll a die. You may keep the result as your score, or you may roll one more time, in which case you must take the second result. A strategy for this game is a rule of the form "keep the first roll if it is at least some value." Which value is best?

The code below simulates 100,000 plays of the game. It generates a first roll and a second roll for every play, and then uses `np.where()` to apply each of three strategies: keep the first roll if it is at least 4, at least 5, or equal to 6.

```
np.random.seed(11)
first = np.random.choice(range(1, 7), size=100_000)       # First roll of each play
second = np.random.choice(range(1, 7), size=100_000)      # Second roll, used only if needed

for keep in [4, 5, 6]:
    score = np.where(first >= keep, first, second)        # Apply the strategy
    print(keep, np.mean(score))
```

The estimated expected scores are 4.2493 for keeping a first roll of 4 or more, 4.1673 for keeping 5 or more, and 3.9182 for keeping only a 6. The best of the three strategies is to keep a first roll of 4, 5, or 6.

For this small game, the exact values can be calculated: they are 4.25, 4.1667, and 3.9167. The estimates are each within 0.002 of the true value. For a game such as chess or Go, exact calculation is impossible, and simulation is the practical alternative. AI systems that play such games estimate the value of a move by simulating many possible continuations of the game. In reinforcement learning, the quantity being estimated is called the **expected reward**.
