## Pseudo-random numbers

The calculations performed by computers are deterministic, which means that they are performed by following a prescribed formulaic process. The results of such a process are, in theory, completely predictable. As a result, computers are not able to generate "truly random" numbers on their own without some input from an external random process.

Computers are, however, capable of generating pseudo-random numbers. A **pseudo-random number** is a number that is generated by a deterministic algorithm but that displays properties that are characteristic of randomness. The algorithms that generate pseudo-random numbers are deterministic, and thus theoretically predictable, but are also complex enough that the results of the algorithms are essentially unpredictable, and thus essentially random, from the perspective of a human.

Although pseudo-random numbers are not technically random, we will often refer to them as "random numbers" for convenience. It should be understood that any reference to "random numbers" generated by a computer is almost certainly a reference to "pseudo-random numbers."

## Applications of pseudo-random numbers

You might be wondering why we care enough about generating random numbers to develop deterministic processes to simulate randomness. Pseudo-random number generation is actually an extremely useful tool in many different fields. It can be used to simulate complicated systems, numerically test hypotheses, estimate probabilities, and introduce unpredictability.

Some specific applications of pseudo-random numbers are provided below:

- Simulating a complex, unpredictable system such as the stock market or weather systems.
- Calculating probabilities associated with an experiment by repeatedly simulating the experiment and then observing the simulated results. This technique is known as Monte Carlo simulation.
- Introducing random or unpredictable elements into a game.
- When designing an environment within which to train an artificial intelligence agent, pseudo-random numbers can be used to introduce unpredictable elements to which the agent must learn to react.
- It is often useful to include a degree of unpredictability in the behavior of an artificial intelligence agent. This can be accomplished using pseudo-random number generation.
- If studying or developing a new machine learning technique, pseudo-random number generation can be used to generate data sets that can be used to test the technique.

## Seeds and reproducibility

As we have discussed, pseudo-random numbers are not truly random. They are generated by a deterministic process. In order for the numbers to appear random, and to behave unpredictably, the process typically involves an input that is unobservable, or that cannot be accurately measured by the user. An example of such an input might be the last 4 decimal digits in the clock time of the computer running the algorithm, measured in millionths of a second. The value of such an input cannot be accurately measured or predicted by a human when the algorithm is running.

A **seed** is an initial value or input that is used to generate a sequence of random numbers. Given the seed value, a random process will always produce the same sequence of pseudo-random results. However, small changes in the seed value will almost certainly result in drastically different pseudo-random results.

By default, pseudo-random processes typically use something like clock time as the seed for the algorithm when it is executed. However, many systems that allow for pseudo-random number generation provide the option for the user to manually set the seed. Being able to set the seed for a random process is crucial for the sake of **reproducibility of results**. When running an experiment that involves pseudo-random numbers, if a seed is manually set before any random numbers are generated, then the process can be repeated later with the exact same results by using the same seed.
