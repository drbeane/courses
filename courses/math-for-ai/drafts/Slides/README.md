# MATH 309/509 Math for AI: slide decks

One Markdown deck per topic, with the same file name as its lesson in `../Lessons/` (`Week NN/WNN-TN - Title.md`). There are no decks yet.

## Format
- Slides are separated by a line holding only `---`. Front matter (`marp: true`) lets the files render as slides with the Marp extension for VS Code. Sync removes it.
- Speaker notes are HTML comments (`<!-- ... -->`). Sync removes them.
- A slide that starts with `# ` is a title slide. Other slides start with `## `.
- Math is written as in the lessons: `$...$` inside a line and `$$...$$` on a line of its own.
